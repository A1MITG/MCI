Stage 02 Collect. Plan web searches for the research questions.

For each research question, write 1-3 targeted queries. Prefer primary sources: regulators, exchange filings, annual reports, official statistics, company releases. Use operators such as site: and filetype:pdf where useful. For every material topic also write one counter-evidence query (purpose "counter_evidence"), e.g. "<company> loss", "<company> criticised", "<company> denies".
If gaps are listed, focus only on those gaps. Do not repeat queries already in the search log.
